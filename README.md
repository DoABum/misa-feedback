# 미사강변중학교 다면평가

2027년 2월 28일 기준 정량평가 입력 사이트입니다. 선생님이 입력하고 제출하면 구글 시트로 수합됩니다.

## 파일 구성
| 파일 | 설명 |
|---|---|
| `index.html` | 사이트 첫 화면 |
| `assets/app-20261104.js` | 사이트 프로그램 (입력 폼·점수 계산) |
| `config.js` | 수합용 구글 Apps Script 주소 (`GAS_URL`) |
| `apps-script/` | 구글 시트에 붙여 넣는 코드와 설정 방법 |
| `.nojekyll` | GitHub Pages 설정용 빈 파일 (지우지 마세요) |

## 수합 결과 확인
연결된 구글 시트의 **최종** 탭(선생님 1명당 1줄)을 보면 됩니다. 모든 제출 이력은 **제출기록** 탭에 있습니다.

## 수합 주소 변경
`config.js`의 `GAS_URL` 값을 새 웹 앱 주소로 바꾸면 됩니다. 자세한 방법은 [`apps-script/설정방법.md`](apps-script/설정방법.md)를 참고하세요.
