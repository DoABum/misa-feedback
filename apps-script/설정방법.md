# 구글 시트 수합 설정 방법 (약 5분)

## 1. 구글 시트 만들기
1. https://sheets.new 에 접속해 새 스프레드시트를 만듭니다. (이름 예: `2027 다면평가 수합`)
2. 상단 메뉴 **확장 프로그램 → Apps Script** 를 클릭합니다.

## 2. 스크립트 붙여 넣기
1. 열린 편집기의 `Code.gs` 내용을 모두 지웁니다.
2. 이 폴더의 `Code.gs` 내용을 전부 복사해서 붙여 넣고 💾 저장(Ctrl+S)합니다.

## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포** 클릭
2. 톱니바퀴(유형 선택) → **웹 앱**
3. 설정
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** 클릭 → 권한 승인 창이 뜨면 본인 계정 선택 → (경고가 나오면) **고급 → 이동(안전하지 않음)** → 허용
5. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/..../exec`) 을 복사합니다.

> 학교(교육청) 구글 계정에서 "모든 사용자" 항목이 안 보이면, 개인 Gmail 계정으로 시트를 만들어 주세요.

## 4. 사이트에 주소 넣기
`config.js` 파일을 메모장으로 열어 따옴표 안에 URL을 붙여 넣고 저장합니다.

```js
window.GAS_URL = "https://script.google.com/macros/s/..../exec";
```

그 다음 폴더 전체를 깃허브에 올리면 끝입니다.

## 수합 결과 보는 법
제출이 들어오면 시트에 탭 2개가 자동으로 생깁니다.

| 탭 | 내용 |
|---|---|
| **최종** | 선생님 1명당 1줄. 같은 성함으로 다시 제출하면 최신 내용으로 덮어씀 → **이 탭을 보시면 됩니다** |
| **제출기록** | 모든 제출 이력 (수정 전 내용 포함) |

엑셀이 필요하면 **파일 → 다운로드 → Microsoft Excel**.

## 주의
- `Code.gs`를 나중에 고치면 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포** 를 해야 반영됩니다. (URL은 그대로 유지)
- "새 배포"를 다시 하면 URL이 바뀌므로 `config.js`도 같이 바꿔야 합니다.
- 같은 성함 기준으로 덮어쓰므로, 동명이인이 있으면 성함 뒤에 교과 등을 붙여 구분해 주세요.
